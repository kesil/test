# JIMOTHY — Sprite Kit & Game Design Handoff

Asset kit for a side-scrolling game starring Jimothy, the real short-spined raccoon
from Ballard, Seattle. Everything here was procedurally generated by Python/Pillow
scripts (included in `generators/`) so any asset can be regenerated, tweaked, or
extended programmatically.

## 1. Who Jimothy is (art law — do not violate)

Jimothy has short-spine syndrome. The caricature rules, derived from photos and
The Oatmeal's drawing:

1. **He is ONE fuzzy mound.** There is no separate head shape. The face (single
   eye, soft mask patch, short snout bump) is embedded flat on the front-lower
   surface of the mass. Back arches high; face sits low-front.
2. **Spindly bare limbs with splayed 3-finger paws**, clustered under the FRONT
   half of the body. The rear third of the mound hangs cantilevered behind them.
3. **Small rounded ears ON TOP of the mound**, spaced apart (one front, one back).
4. **Stub tail**: a small ringed pom at the upper back, subordinate to the body.
5. Sketchy directional fur strokes + scruff spikes on the silhouette.
6. All sprites face RIGHT; flip horizontally for left.

## 3. Atlas conventions

- Frame size 80x64, one animation per row, frame index = column.
- `duration_ms` is per-frame; `loop` false = play once then hold/return.
- v5 atlas `anchors`: feet baseline y=58, mouth (63,38) for carry-item
  compositing, ledge grip (49,11), swim waterline y=44, throw projectile spawn
  (64,28), swipe hit center (58,40).
- v5 atlas `hitboxes`: stand / sneak_swim / roll / ko. v6 shares the same anatomy.
- Special rows: `control` (Animal Control) intentionally bleeds off the top edge
  (he is huge; only legs + net are visible). `hitflash` is a white silhouette for
  damage feedback. `star_power` frames alternate gold/white — cycle at 80 ms.

16x16, Ballard alley theme: sky/clouds/skyline (incl. Space Needle w/ beacon),
moon, ground (top/mid/edges), brick (+window/parapet), fence, crate, cardboard

grid coords + a collision class:
`none | solid | platform | hazard | bounce | checkpoint | water | climb | door`.

## 6. Game design seeds (mechanics the art already supports)

- **Core loop:** scurry through Ballard alleys at night, forage trash (dig,
  pickup, eat), avoid hazards, reach the trash-can and **trashdive** to end the
  level (the dive is the flag-pole moment).
- **Moveset:** run/jump (3-phase arc + land squash), roll = dash, walljump +
  climb + hang for verticality, sneak past sleeping threats, swim/dive in canal
  sections, balance on power lines (pole_wire tiles + balance anim), push crates,
  cart_ride for downhill autoscroller levels.
- **Combat-lite:** swipe + pounce; throw soda cans; hitspark on connect;
  hitflash on taking damage.
- **Enemies/hazards:** rat (ground patrol), gull (dive-bomber), possum
  (neutral rival NPC — races you to food), **Animal Control** (chase sequences:
  giant legs + descending net, screen-edge pressure), cones/glass (static),
  zap wires (electrocution gag), freeze puddles (frozen), steamroller (flat).
- **Powerups:** cookie=heal, pizza=chonk mode (bigger, breaks crates, slower),
  shiny can=star_power invincibility, bottle rocket=jetpack section, balloons/
  umbrella=descent control, mecha suit=boss-fight armor, wizard hat=??? secret.
- **Progression flavor:** king-of-trash throne as world-clear screen; disco as
  a hidden dance minigame; emotes+bubbles power a light dialogue system with
  the possum.
- **HUD:** hearts row, portrait, collectible counters using the item sprites.

## 7. Suggested tech (owner's established pattern)

Single-file HTML5 canvas game; sprite sheets embedded base64 or fetched
alongside; atlas JSONs drive a state machine (state -> row/frames/durations).
Dev pattern: Python edit scripts with anchored replacements, node syntax checks,
headless unit tests, seeded playtest harness. Integer-scale rendering
(image-rendering: pixelated), camera with look-up/down using the `look` frames.
